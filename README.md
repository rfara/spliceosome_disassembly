# spliceosome_disassembly
This repository contains analysis scripts for RNA sequencing experiments from spliceosomes undergoing disassembly. The results have been published as part of Boreikaite et al. (2026):

Paper reference goes here.

The relevant raw sequencing data can be retrieved using the GEO accession GSE329374. The analysis of the two datasets (shortread and longread) can be reconstructed using the snakemake pipelines contained within the experiment directories. More information about how to execute those pipelines is contained within the README.md files in those directories.
